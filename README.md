# Sports Domain Tracker

A checklist tracker for every sport in the sports domain: Football, Foot Tennis, Fusion Relay, Pickleball, Amazing Race, Dodgeball, Table Tennis and Tug of War.

Each sport has six categories: **Referees, Venue, Logistics, Sport-specific requirements, Volunteers, Dry-run**.

## Run it
Open `index.html` in any browser (double-click it). You don't need a server or an internet connection.

## Where the data came from
- **Sports domain logisitcs requirment** (Google Sheet): equipment, logistics, standby rooms, scoring sheets
- **Schedule for sports domain** (Google Sheet): Referee Tracker, turf/court bookings and costs, timings

Items tagged **SUGGESTED** are not in the sheets. They are starter tasks you can edit or delete.

## Using it
- Tick items as they're done. Progress saves automatically in your browser.
- Hover an item to edit (✎) or delete (✕) it. Use the box at the bottom of a category to add items.
- **Export** downloads a backup `.json` file. **Import** restores from one, so you can move to another device.
- **Reset to sheet** puts one sport back to its original sheet data.
- To change the default lists, edit `data.js`.
